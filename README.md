# Super Optimizador

Aplicación portable para Windows que reúne ajustes de rendimiento, limpieza de
RAM, herramientas del sistema y un overlay de métricas. Los tweaks se aplican
con confirmación individual, backups y registro de cambios.

## Compilar desde el código fuente

Requiere Node.js instalado en Windows.

```powershell
npm install
npm run dist:portable
```

El ejecutable portable se genera en:

```text
dist/Super-Optimizador-Portable-0.1.0.exe
```

Para ejecutar la aplicación durante el desarrollo:

```powershell
npm start
```
